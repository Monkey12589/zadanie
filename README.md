# Junak - Legend on Wheels (UX/UI Web Project)

A conceptual UX/UI design and frontend project dedicated to the iconic Polish motorcycle brand **Junak**, created as a school homework assignment. 

The website focuses on clear information architecture and a clean user interface (UI) to effectively tell the brand's story. It is live and accessible at:  
👉 **[Live Demo on Netlify](https://homework-junak-copy.netlify.app/)**

## 🏍️ UX/UI Design Concept
The primary objective of this project was to outline a smooth user journey (UX) for visitors looking to explore the heritage and current lineup of Junak. Instead of cluttering the layout, the focus was placed on a minimalist, highly intuitive user interface (UI) divided into logical content blocks.

### ✨ UI Elements & Layout Features:
*   **Intuitive Navigation:** A clean header menu utilizing clear iconography to help users quickly identify target pages (*Gallery, Catalog, Contact*).
*   **Visual Hierarchy:** Defined headings and structural spacing that allow users to scan historical facts, offers, and models effortlessly.
*   **Product Spotlights:** A neatly ordered list presenting popular flagships (*Junak M16, S300, 125*) with tailored descriptions highlighting their specific riding purpose.
*   **Multimedia Integration:** An embedded video section designed to increase user engagement and complement the written copy dynamically.

## 🛠️ Built With
The project was coded using standard web core technologies to keep the source lightweight and fully focused on the visual presentation:
*   **HTML5** – Semantics, UI layout, and core structure.
*   **CSS3** – Typography, layout compositions, color scheming, and custom navigation styles.
*   **JavaScript** – Basic interactivity and page logic.
